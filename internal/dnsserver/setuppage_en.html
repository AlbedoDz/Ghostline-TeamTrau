iPhone / iPad

  2. Open Settings › Profile Downloaded and install it.
  3. Required: open Settings › General › About › Certificate Trust Settings and turn on Ghostline LAN CA (Full Trust). Without this step the iPhone cannot use the DNS and loses the internet on this Wi-Fi.
  4. Check Settings › General › VPN & Device Management › DNS: Ghostline DNS is selected.

The encrypted DNS is used only on that Wi-Fi; on mobile data and other networks the iPhone uses its usual DNS.

When this computer is off or Ghostline is disconnected, the iPhone loses the internet on this Wi-Fi. To get it back, open Settings › General › VPN & Device Management › DNS and choose Automatic, or remove the profile.

If this computer is often off, use plain DNS instead: Settings › Wi-Fi › (i) › Configure DNS › Manual with this computer's IP address. It needs no certificate and is easy to switch back to Automatic.

The iOS profile is not available. You can open Settings › Wi-Fi › (i) › Configure DNS › Manual and enter this computer's IP address. No certificate is needed.

Android

Turn off Private DNS, then set the DNS of your home Wi-Fi to this computer's IP address (static IP settings). No certificate is needed.

Steam Deck, TV, consoles, router

Set the DNS server of your home network to this computer's IP address. Set it for your home Wi-Fi only, not for every network.

Every device set up this way loses the internet while this computer is off or Ghostline is disconnected.

Other computers (DNS-over-HTTPS)

Download the certificate, add it to the trusted root certificates, then use the DoH address shown in Ghostline.
